# Auriculo - Imagens

Banco de imagens extraídas das **Apostilas Pro Salus 2026** (Auriculomedicina da Escola Huang Li Chun), usadas como base do Sistema Aurículo no Notion.

## Conteúdo

- **270 imagens** únicas embarcadas dos PDFs das 3 apostilas oficiais
- Todas em `embedded/` com nomenclatura `AP{N}-P{NNN}-img{XX}-{hash}.png`

## Uso

URLs raw:

```
https://raw.githubusercontent.com/thiaum-droid/auriculo-imagens/main/embedded/AP1-P028-img01-641bc3ae72b7.png
```

São embarcadas nas páginas de Pontos do Sistema Aurículo no Notion.

## Mapeamento

`embedded/_index.json` traz os metadados (apostila, página, dimensões, texto da página onde apareceu) pra cada imagem.
